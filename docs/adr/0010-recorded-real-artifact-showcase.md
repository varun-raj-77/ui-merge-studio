# ADR 0010: Recorded real-artifact Showcase

## Status

Accepted — 2026-07-27.

## Decision

The hosted Showcase is generated by `npm run showcase:prepare` from the controlled repository’s exact refs. Preparation uses `FeatureSliceAnalyzer` and `CandidateGenerator`, runs real verification, builds four detached exact-commit worktrees with relative Vite assets, exports static output, and derives a sanitized typed report and generated manifest.

Preparation writes noisy intermediate runs to ignored `apps/studio/public/showcase-runs/`, then promotes only the current verified 64-candidate package to tracked `apps/studio/public/showcase/`. The tracked report and generated manifest use this stable public path. `npm run showcase:promote` can repeat the promotion for an already prepared run; it verifies every source and copied artifact hash before replacing the canonical package.

Production builds do not regenerate candidates. `npm run build` validates the tracked canonical package and then runs Vite, which copies it into `apps/studio/dist`. A clean checkout therefore needs only tracked repository content and locked npm dependencies; `.ums`, generated fixtures, worktrees, test results, and prior `showcase-runs` are not build inputs.

`npm run build` only validates and packages existing recorded evidence. Vercel serves Studio and the artifact directories; it never runs Git or candidate generation.

## Integrity model

The report contains repository-relative facts only. A normalized manifest hash excludes volatile `generatedAt`; directory hashes cover sorted relative file paths and bytes. Validation refuses malformed commits, incomplete selections/gates, unavailable evidence links, `.ums` or prompt-history paths, absolute local paths, missing artifacts, hash mismatch, and manifest drift.

## Consequences

The public proof is reproducible and skeptical-engineer auditable, but intentionally limited to one exact fixture combination. Source annotations live outside sandboxed artifact frames. Supporting more subsets requires preparing and recording separate genuine candidates.
