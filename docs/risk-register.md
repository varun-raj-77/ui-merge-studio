# Risk register

| Risk | Mitigation |
|---|---|
| Hosted replay appears to perform Git operations | Persistent sample label, explicit local-engine explanation, and replay wording near evaluation. |
| Visual highlight misses the real control | Linked feature regions and browser assertions that required control centres fall inside their regions. |
| Evidence drifts from selections | Instrumented browser selections drive analysis; preparation writes a hashed run report and typed replay manifest that build validation checks. |
| Unrecorded combinations look successful | Only the committed safe pair replays success; every other unproven pair is labelled unrecorded. |
| Incompatible selection mutates source | Contract compatibility is evaluated before candidate work and produces a plain-language refusal. |
| Fixture-specific semantics leak into the engine | Product names remain in Showcase metadata and controlled fixture source, never generic analyzers. |
| External proof is overgeneralized | README and limitations explicitly bound it to one conventional Vite repository. |
| Temporary processes or worktrees leak | Controllers use explicit lifecycle cleanup and verification tests audit cleanup. |
| A moved foundation or source ref changes a published plan's meaning | Plans pin exact commits; generation resolves current refs and refuses stale branch heads before mutation. |
| Foundation UI is mistaken for partial feature selection | Plain-language descriptions and a separate dock group state that all foundation changes are included. Same-branch additions normalize away. |
| Merge-base assumptions lose foundation work | Git resolves and pins the common ancestor; integration tests compare every foundation-changed path against the candidate. |
| Overlap is refused too broadly or accepted unsafely | Ordinary file overlap is analyzed structurally; stable shared-contract replacement produces a product-language refusal before candidate presentation. |
| Hosted preview appears to check out a selected foundation | The result is labelled Configured preview; documentation and UI reserve actual Git/worktree claims for the local engine. |
